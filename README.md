# Collins Ikechukwu

My portfolio. Built with Next.js, GSAP and Lenis.

```bash
pnpm install
pnpm dev
```

Set `GITHUB_TOKEN` in `.env.local` for live GitHub stats (see `.env.example`). Without it, the site uses the snapshot in `src/content/github.json`. Refresh that with `pnpm sync:github`.

Content lives in `src/content/`.
